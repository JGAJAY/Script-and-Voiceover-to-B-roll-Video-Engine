# Test Pack & Outputs Directory

This directory stores outputs generated by the test suite and batch runner CLI (`src/cli/batch_runner.py`).

## Inputs Available in `test_pack/inputs/`:
1. `01_tutorial_tech.json`: Software engineering tutorial in English (India) with 16:9 and 9:16 aspect ratios.
2. `02_news_summary.json`: Professional broadcast economic news report in English (US).
3. `03_product_promo.json`: High-energy marketing product video for agency workflow.
4. `04_travel_story.json`: Meditative personal narrative through mountain valleys with riverbank nature.
5. `05_hindi_voiceover.json`: Multilingual Hindi narration (`hi-IN`) on creative empowerment.
6. `06_tamil_voiceover.json`: Multilingual Tamil narration (`ta-IN`) on next-generation innovation.
7. `07_abstract_statistics.json`: Hard case testing abstract philosophy ("trust is earned slowly") and future statistics ("sales grew 40% in 2025").
8. `08_double_meanings.json`: Hard case testing contextual disambiguation (value, bank, cloud, python).
9. `09_sensitive_news.json`: Hard case testing solemn, sensitive memorial narrative with respectful sober stock.
10. `10_scene_list_visual_hints.json`: Pre-segmented IncuBrix scene list with custom visual hints per scene.

## Running the Batch Runner Against the Live API:
```bash
python -m src.cli.batch_runner --input test_pack/inputs --output test_pack/outputs --api-url http://localhost:8000
```
This automatically produces:
- `video_16-9.mp4`, `video_9-16.mp4`
- `captions.srt`
- `timeline.json`
- `manifest.json`
- `batch_summary.json`
